# Lists Forever

Lists Forever - это социальная сеть, которая позволяет пользователям создавать
различные листы (рейтинги, списки желаемого, ...), делиться ими с другими
пользователями, а также обсуждать и оценивать их.

## Функции:
- Создание листа на любую тему (игры, сериалы, аниме, ...)
- Обсуждение, оценивание, копирование и отображение листов
